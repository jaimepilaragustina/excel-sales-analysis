# Análisis de ventas y clientes en Excel

Proyecto de análisis de ventas realizado en Excel para una distribuidora ficticia de lubricantes y servicios de mecánica.

## Objetivo

Analizar las ventas y obtener información útil sobre facturación, productos, clientes, localidades y medios de pago.

## Herramientas utilizadas

* Microsoft Excel
* Tablas dinámicas
* Fórmulas y funciones de Excel
* Gráficos
* Dashboard

## Principales resultados

* **Facturación total:** $833.700
* **Cantidad de ventas:** 12
* **Clientes:** 5
* **Ticket promedio:** $69.475
* **Producto con mayor facturación:** Aceite 5W30 — $269.500
* **Producto más vendido:** Bujías — 20 unidades
* **Cliente con mayor facturación:** Mecánica Sur — $237.700
* **Localidad con mayor facturación:** Bahía Blanca — $524.000

## Contenido del proyecto

El archivo incluye:

* Base de datos de ventas
* Análisis de productos
* Análisis de clientes
* Análisis por localidad
* Análisis de medios de pago
* Dashboard
* Análisis general de resultados
